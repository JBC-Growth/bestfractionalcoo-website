# Best Fractional COO - Website Mockup

Static mockup for bestfractionalcoo.com: a fractional COO practice for growing law firms.

## Pages

All pages live in `index.html` and switch by URL hash:

- `#home` - hero, readiness checklist, services preview, process, about preview
- `#services` - Operational Health Assessment, 90-Day Operating Reset, Fractional COO Partnership
- `#law-firms` - law firm operations
- `#pricing` - price cards, comparison table, FAQ
- `#about` - bio and track record (placeholders)
- `#insights` - article list and Founder Bottleneck Scorecard
- `#contact` - Book a Fit Call form (mockup only, does not submit)

## Viewing

Open `index.html` in a browser. No build step.
